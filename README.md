# 🎓 Exam Sitting Arrangement System

A full-stack web application for managing exam seating arrangements 
in colleges — with separate portals for Admin and Students.

<br/>

## 🚀 Features

### 👨‍💼 Admin Portal
- Upload and manage exam routines
- Add, edit, delete student records
- Generate and assign seating arrangements room-wise
- Changes reflect instantly on student dashboard

### 👨‍🎓 Student Portal
- Login with roll number
- View today's exam seating info (room, bench, seat number)
- Visual classroom seat grid (BookMyShow-style)
- Download admit card as PDF
- Other exam dates remain locked until the day

<br/>

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React.js, Vite, React Router |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas |
| Styling | Custom CSS (Orange + White theme) |
